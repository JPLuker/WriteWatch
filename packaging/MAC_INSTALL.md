WriteWatch for macOS

Requires macOS 15 or newer. Choose AppleSilicon for M-series Macs or Intel for Intel Macs.

1. Open the DMG and drag WriteWatch into Applications.
2. Open WriteWatch from Applications.
3. This independent testing build has no Apple Developer ID signature or notarization. If macOS blocks the first launch, open System Settings > Privacy & Security, find the blocked WriteWatch entry and choose Open Anyway. Confirm only if you downloaded this build from JPLuker/WriteWatch on GitHub.

Do not disable Gatekeeper globally. If macOS reports malware rather than an unidentified developer/unverified app, stop and report the exact message.

The ZIP contains the same app as an alternative to the DMG. A local ad-hoc signature is used for bundle integrity; it is not an Apple trust endorsement.

Session history normally lives under ~/Library/Application Support/WriteWatch/WriteWatch. The document you select is only read, never modified. No accounts or online connections are required.
