# WriteWatch v0.6.2 — compact session setup

- Goal settings moves to the bottom left of setup; Start session sits on the right.
- Goal controls open in a small dialog with Save goal and Cancel.
- The selected target appears on the Goal settings button. No target is required.
- Writing / Revision stays visible in setup. Existing history is unchanged.

Windows, Mac, Linux AppImage and Debian installer downloads are available. Linux requires glibc 2.39+; macOS requires 15+ and remains ad-hoc signed.
