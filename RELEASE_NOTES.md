WriteWatch 0.2.0 — support for more writing apps.

- New readers for Final Draft, DOCX, OpenDocument, RTF, Markdown, Fountain, plain text, HTML, EPUB, selectable-text PDF and AbiWord, alongside Fade In.
- The same Start / Pause / Done → Copy workflow, with no squares, document text or filenames in shares.
- New Formats & apps guide explaining direct saves versus exports.
- File-change detection avoids repeatedly parsing unchanged documents.
- Existing numeric-only history remains compatible.

Download the Windows Setup EXE or Linux AppImage below. Portable ZIP and tar.gz are also available. Linux requires Ubuntu 24.04 / glibc 2.39+ or a compatible distribution.

Save before starting, pausing or finishing. Browser-only apps and proprietary projects require a refreshed local export; native Google Docs shortcuts, Pages and Scrivener project files are not supported. PDF counts are approximate and scanned PDFs require OCR elsewhere. This is a testing release; format fixtures do not replace validation with your documents.
