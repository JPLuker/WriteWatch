Initial testing release of WriteWatch for Windows x64 and Linux x86_64.

- Start / Pause / Resume / Done writing and revision sessions.
- Local saved-file monitoring for Fade In and OSF scripts.
- One-click plain-text sharing for your writers group — no squares, script text or title.
- Optional PNG share cards, local history, weekly totals and streaks.
- Numeric-only checkpoints for interrupted sessions.

**Windows:** choose the Setup EXE or portable ZIP. **Linux:** choose the AppImage or tar.gz; Ubuntu 24.04 / glibc 2.39+ baseline. Packages are unsigned.

Save in Fade In before starting, pausing or finishing. Time is manually controlled; words reflect net saved changes, not all keystrokes or rewrite effort. This first release needs hands-on validation with your actual Fade In documents.
